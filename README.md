# Mi Proyecto: Clima Click 

¡Hola! Este es mi proyecto para el **Módulo 2** . Construí esta página para mostrar el clima de las principales ciudades  de Chile, de una forma rápida y clara, incluyendo mi ciudad, Coronel.

### ¿Qué usé para hacerlo?

Para que la página funcionara y se viera bien, apliqué estas herramientas:

* **HTML5:** Lo usé para que toda la página esté bien organizada y tenga una estructura profesional.
* **Bootstrap 5:** Con esto logré que la página se vea linda y se adapte  a  celulares. 
* **JavaScript:** Lo usé para  no tener que escribir cada tarjeta a mano. Creé un listado de 11 ciudades que se cargan solas con una función, así el código queda mucho más limpio y ordenado.
* **Font Awesome:** Cambié los emojis por estos iconos para que el sol, las nubes y la lluvia se vean mucho más profesionales.
* **CSS Personalizado:** Le di mi toque especial con colores y efectos para que las tarjetas se muevan cuando pasas el mouse por encima.

### ¿Cómo puedes revisar mi trabajo?

1. Descarga los archivos de este repositorio.
2. Busca el archivo llamado **index.html** y ábrelo en tu navegador favorito.
3. Haz clic en los botones de "Ver detalle" para navegar entre la página principal y el pronóstico de cada ciudad.
